# 角色参考图库

这个目录用于存储主要角色的标准参考图，用于通过即梦 AI 图生图 API 保持角色形象的一致性。

## 使用说明

### 1. 生成角色参考图

在豆包 App 中为每个主要角色生成1-2张高质量的参考图：

**巫巫女**
- 要求：正面或3/4侧面，面部清晰，特征明显
- 提示词建议：
  ```
  巫巫女，乱蓬蓬的紫头发，尖尖的鼻子，穿着彩虹披风，
  温柔的女巫，温馨治愈风格，柔和的光线，童话插画风格
  ```
- 保存为：`巫巫女_reference.jpg`

**莉莉**
- 要求：6岁小女孩，扎着小辫子，穿着粉色连衣裙
- 提示词建议：
  ```
  莉莉，6岁小女孩，扎着小辫子，穿着粉色连衣裙，可爱活泼，
  温馨治愈风格，柔和的光线，童话插画风格
  ```
- 保存为：`莉莉_reference.jpg`

**欣欣**
- 要求：和莉莉差不多大，梳着丸子头，穿黄色羽绒服
- 提示词建议：
  ```
  欣欣，6岁小女孩，梳着丸子头，穿黄色羽绒服，戴毛线帽，
  手里拿着画本和画笔，温馨治愈风格，柔和的光线，童话插画风格
  ```
- 保存为：`欣欣_reference.jpg`

**森林小动物**
- 可选：朵朵、白白、球球、慢慢、跳跳
- 保存为：`角色名_reference.jpg`

### 2. 使用参考图

自动化脚本会自动使用这些参考图生成新故事的封面，保持角色形象的一致性。

### 3. 风格关键词

每次生图都会使用以下风格关键词，确保整体风格连贯：
- 温馨治愈风格
- 柔和的光线
- 童话插画风格
- 色彩明亮温暖
